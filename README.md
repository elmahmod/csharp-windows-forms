# C# Windows Forms

A collection of **Windows Forms lessons and small desktop projects in C#**. The repository separates practice with individual UI controls from complete applications.

## Learning Examples

Browse [WindowsForms](WindowsForms) for organized examples covering:
- Basic controls, input controls, and media/display controls
- Lists, trees, containers, menus, and dialogs
- Timers, date/time controls, drawing, and helper controls
- MDI containers and other practice exercises

**Solution:** [WindowsForms.slnx](WindowsForms/WindowsForms.slnx)

## Getting Started

1. Open **Visual Studio** on Windows with the **.NET desktop development** workload installed.
2. Open one of the solution files above or the desired project's `.csproj`.
3. Select a startup project, build, and run.

These are independent learning exercises; some use images and resources stored alongside their source files.

## Purpose

Practice WinForms **one control at a time**, then combine those lessons into small desktop programs.

For C# language and .NET theory notes, see [C# Programming](https://github.com/elmahmod/csharp-programming).
